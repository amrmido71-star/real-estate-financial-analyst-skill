# النموذج المتكامل للتطوير العقاري V1.2

> المحرك المركزي — `افتراضات المشروع → ... → العوائد / السيناريوهات / المخاطر`  
> محرك زمني شهري، على مستوى الوحدة، موثق، ثنائي اللغة

## المعمارية

```
assumptions.py (افتراضات المشروع: 7 مجموعات، تحقق، hash)
      ↓
integrated_model.py (النموذج المتكامل)
      ├─ محرك شهري: _months_between / _add_months / MonthlyRow (36 افتراضي)
      ├─ مخزون الوحدات: _build_units (موزعة بالتساوي أو حسب المزيج السعري)
      ├─ تصعيد السعر: إذا لم يكن السعر مقفلاً → (1+g)^سنوات
      ├─ سرعة المبيعات: جدول شهري أو سرعة → وحدات شهرية، مبيعات متعاقد عليها، تواريخ بيع
      ├─ التحصيلات: build_collection_schedule (جدول 5 شرائح + تاريخ التسليم × نسبة التحصيل) → خريطة شهرية
      ├─ الإنشاءات: generate_s_curve (ميزانية، أشهر، نوع) [+ تضخم] → منحنى شهري
      ├─ التكاليف: تسويق/عمولة %GDV موزعة على أشهر البيع، مصاريف ناعمة/حكومية موزعة شهرياً
      └─ التمويل: سحب حسب LTC (نسبة الدين × تكلفة شهرية مقيدة بفجوة التمويل)، فائدة مرسملة/نقدية، سداد من الفائض، ضخ/توزيع حقوق ملكية
      ↓
العوائد (سنوية)  GDV/GDC/ربح/هامش + IRR/NPV غير مدعوم/مدعوم/حقوق ملكية + MIRR + MOIC + فترة استرداد
      ↓
المطابقة → تحقق الوحدات، GDV مقابل مجموع الوحدات، التحصيلات مقابل النسبة، تسوية النقد والدين
      ↓
الصحة 0-100 → صحي / مراقبة / حرج + لوحة مؤشرات
```

## أهم المعادلات

- GDV = مجموع أسعار الوحدات (المباعة) — إجمالي قيمة البيع
- GDC = مجموع تكاليف التطوير (أرض+إنشاء+ناعمة+تسويق+عمولة...)
- الربح = GDV - GDC، الهامش = الربح/GDV
- ذروة التمويل = |أصغر رصيد تراكمي للتدفق المدعوم| (قبل حقوق الملكية)
- IRR شهري ثم سنوي (1+شهري)^12-1، NPV شهري، MOIC = توزيعات/حقوق مستثمرة
