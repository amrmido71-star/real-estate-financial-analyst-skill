# Financial Modeling — Core Rules

- Never fabricate data. Report Missing Data | Impact | Required Input.
- Distinguish Actual / Forecast / Assumption.
- Every KPI traceable to source + formula.
- Preserve source as READ-ONLY.
- Validation Gate: inputs, units, GDV, sales, collections, construction, cash, debt, equity, returns must PASS before reporting.
- Calculations reproducible via scripts/run_analysis.py.
